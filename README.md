# 本地生活商户入驻微信小程序

原生微信小程序前端项目（WXML / WXSS / JavaScript）。

当前状态：项目目录与 Git 仓库已初始化，等待确认的 UI 效果图文件可读取后开始首页的 1:1 还原。

## 设计参考图

原始的低清设计包保持不改动。`design-reference-hd/` 保存基于原始构图重建的 10 张高清开发参考图，用于补足模糊图标、商户图片与乱码文字；这些图不作为前端页面背景使用。

## 约定

- 页面、组件、模拟数据与本地存储会分层组织；不接入正式业务接口。
- 首页完成后先进行真机尺寸预览与设计稿对照，再进入其余页面。
- 设计稿中不清晰的图片、图标会在保持原有视觉语言的前提下修复或重构。
